# Salesman Lead Tracker

This is a mobile-friendly web app. It records leads on the phone, shows overdue pending follow-ups in red, and lets each user export their data as CSV.

## Use on a phone

Host this folder on any HTTPS web hosting service, then open its link on each salesman’s phone. In Chrome, tap the browser menu and choose **Install app** or **Add to Home screen**.

## Important

This first version stores data only in that phone's browser. Different salesmen will not see each other’s leads, and clearing browser data removes that phone's records. A shared team version needs a secure online database and user logins.
